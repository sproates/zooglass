## Download and check

From `workbench/`, choose an empty evidence directory:

```sh
checksums="$(pwd)/evidence/ha-static-20261128.sha256"
mkdir /tmp/ha-retained-evidence
gh release download ha-static-evidence-20261128 --repo sproates/zooglass \
  --pattern ha-static-20261128.tar.gz --dir /tmp/ha-retained-evidence
(cd /tmp/ha-retained-evidence && shasum -a 256 -c "$checksums")
python3 scripts/evidence-archive.py verify /tmp/ha-retained-evidence/ha-static-20261128.tar.gz
```

After verifying the checksum and bounded archive inventory, extract it into a new
directory and run the included auditor:

```sh
mkdir /tmp/ha-retained-evidence/extracted
tar -xzf /tmp/ha-retained-evidence/ha-static-20261128.tar.gz -C /tmp/ha-retained-evidence/extracted
cd /tmp/ha-retained-evidence/extracted/public-evidence
python3 audit-ha-qualification.py normal extra-pauses \
  --manifest frozen-manifest.json --identity frozen-prepared.json --controls controls
```

Re-running the service cases requires preparing the matching repository inputs and
Docker environment. This archive is not a deterministic replay bundle. Release
assets can be removed or replaced; the committed hash pins the reviewed bytes.
